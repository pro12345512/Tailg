# TAILG — موقع تجريبي للدراجات الكهربائية

## التشغيل
- فك ضغط الملف.
- افتح `index.html` في المتصفح.
- اتصال الإنترنت مطلوب فقط لتحميل خط Google Fonts، أما الصفحة نفسها وصورها فتعمل محلياً.

## قبل تسليم الموقع للعميل
1. تأكيد رقم واتساب داخل `script.js` وتعديله إلى رقم العميل الصحيح بصيغة دولية بدون `+`.
2. تأكيد الأسعار والمواصفات والتوفّر؛ الأسعار غير معروضة حالياً لأنها غير موجودة في المواد.
3. استبدال الصور الترويجية بصور منتجات أصلية عالية الدقة إن توفرت.
4. ربط نموذج الاستفسار بنظام فعلي إذا لم يكن واتساب كافياً.
5. استبدال نصوص العرض التجريبي بالمحتوى الرسمي ومراجعة حقوق استخدام شعار وصور العلامة التجارية.

هذا Demo واجهة أمامية HTML/CSS/JS فقط، ولا يحتوي على لوحة إدارة أو قاعدة بيانات.
